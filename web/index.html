Why Mizan?

The name of this site, and what the Quran says about it.

Mizan ميزان is the Arabic word for the balance — the scales. In the Quran it is three things at once: the order God set into creation, the standard of justice revealed with the Book, and the scales on which deeds are weighed on the Day of Judgment. This site is named for it because that is what it tries to do: weigh the Quran's words carefully, and say plainly what balances and what does not.

Counted by script from the corpus: the word ٱلْمِيزَانَ (al-Mizan) occurs in 9 verses, ٱلْمَوَٰزِينَ (al-mawazin, the scales) in 7, and words from the root w-z-n, to weigh, in 21 verses.

The 99 Names of God أَسْمَاءُ ٱللَّهِ ٱلْحُسْنَىٰ

These are the famous ninety-nine — al-Asmāʾ al-Ḥusnā, the Beautiful Names — from the hadith of the ninety-nine names: “Allah has ninety-nine names, one hundred less one; whoever learns them will enter Paradise” (Sahih al-Bukhari 7392; Sahih Muslim 2677). Ninety-nine is not a ceiling: scholars agree the hadith does not limit Allah's names to this number, and the Quran uses more names and attributes of Allah than these 99. Below, each Name is counted in the Arabic text, matched by lemma in the Quranic Arabic Corpus. A Name counts only where the word is used of God; excluded occurrences are listed per Name. 24 Names do not occur in the Quran at all.

Corpus

PrimaryQuranic Arabic Corpus v0.4 (Kais Dukes, University of Leeds, 2011) — corpus.quran.com. Morphological annotation: 77,429 words, 6,236 verses, 114 surahs; each word tagged with part of speech, lemma and root. Licence: GNU GPL.
Obtained viaOfficial download is an e-mail form with no direct file URL; the Java API is a library, not a REST endpoint. The file used here came from the textminingthequran.com mirror of the identical v0.4 file, verified against the corpus's published figures (128,276 lines; 77,429 words; verbatim GPL header).
Cross-checkTanzil Quran Text, Uthmani script (tanzil.net) — display Arabic (copied byte-for-byte, never retyped) and full-text totals. Known difference, not an error: the Corpus counts 77,429 segmented words; Tanzil counts 77,881 space-delimited tokens. Gap of 452 = 448 (112 unnumbered basmalahs × 4 words, in Tanzil, absent from the Corpus except 1:1) + 4 verses where the texts segment words differently (2:181, 8:6, 13:37, 37:130). Counts are never forced to match.

Counting rules

Root-word pairsMatch by ROOT: in the Corpus, then narrow by LEM: to the intended sense (e.g. root jnn gives 201 words, lemma jan~ap — jannah itself — gives 147). One count per word location; prefixes and suffixes need no stripping — the Corpus already segments them.
Names of GodMatch by LEM: with a ROOT: cross-check. A Name counts only where the word is used of God; occurrences predicated of something else are excluded and listed verse by verse in the data.
Co-occurrenceTwo Names co-occur if both appear in the same verse (primary graph) or the same surah (weaker graph). Edge weight = number of shared verses/surahs.
BasmalahThe Corpus contains only the basmalah of 1:1. Counts therefore exclude the 112 unnumbered basmalahs; Tanzil-based surface counts are 112 higher for Allah, Rahman and Rahim, as noted per Name.

Reproduce it

Every number on this site comes from a script in the data/ folder of the repo:

  • python3 data/root_counts_script.py → root_counts.json (re-run regenerates byte-identical JSON)
  • python3 data/names_script.py → names.json + name_edges.json (self-checking; exits non-zero on mismatch)
  • python3 data/scholar_spotcheck.py → 18 anchors for the scholar findings
  • python3 build.py → web/data.js + web/locations.js

Full provenance, file hashes and counting-rule detail: DATA_SOURCES.md. Reconciliation log: RECONCILIATION.md. Methods per finding: METHODS.md.
