Methodology & sources

How every number on this site was produced — and how to reproduce it.

Primary corpus

Quranic Arabic Corpus, version 0.4 (Kais Dukes, University of Leeds, 2011), corpus.quran.com — morphological annotation of the Quran: 77,429 words, 6,236 verses, 114 surahs. Each word is tagged with part of speech, lemma and root.

How it was obtained, stated honestly: the official download page serves v0.4 behind an e-mail form and publishes no direct file URL, and the Java API (JQuranTree) is a Java library, not a REST endpoint. The file used here was fetched from the textminingthequran.com mirror of the identical v0.4 file and verified against the corpus’s own published figures (128,276 lines; 77,429 words; verbatim GPL header block). It was not downloaded directly from corpus.quran.com.

Licence: GNU GPL — verbatim redistribution allowed, changes not allowed. Source named and linked wherever the annotation is used.

Cross-check corpus

Tanzil Quran Text, Uthmani script (tanzil.net). Used for (a) display Arabic in this site, copied byte-for-byte and never retyped, and (b) cross-checking full-text totals.

Known difference, not an error: the Corpus counts 77,429 segmented words; Tanzil counts 77,881 space-delimited tokens in the same 6,236 verses. The gap is 452 = 448 (112 unnumbered basmalahs × 4 words, present in Tanzil, absent from the Corpus except 1:1) + 4 verses where the two texts segment words differently (2:181, 8:6, 13:37, 37:130). Counts are never forced to match.

Counting rules

  • Root-word pairs: match by ROOT: in the Corpus, then narrow by LEM: to the intended sense (e.g. root jnn gives 201 words, but lemma jan~ap — jannah itself — gives 147). One count per word location; prefixes and suffixes need no stripping because the Corpus already segments them.
  • Names of God: match by LEM: with a ROOT: cross-check. A Name counts only where the word is used of God; occurrences predicated of something else (the Book, a person, an object) are excluded and listed verse by verse in the data.
  • Co-occurrence: two Names co-occur if both appear in the same verse (primary graph) or the same surah (weaker graph). Edge weight = number of shared verses/surahs.
  • Basmalah: the Corpus contains only the basmalah of 1:1. Counts therefore exclude the 112 unnumbered basmalahs; Tanzil-based surface counts are 112 higher for Allah, Rahman and Rahim, as noted per Name.

Reproduce it

Every number on this site comes from a script in the data/ folder of the repo:

  • root_counts_script.py → root_counts.json (re-run regenerates byte-identical JSON)
  • names_script.py → names.json + name_edges.json (self-checking; exits non-zero on mismatch)
  • scholar_spotcheck.py → 18 anchors for the scholar findings

Full provenance, file hashes and the counting-rule detail live in DATA_SOURCES.md.

What this site does not do

  • It does not present disputed numerology as settled fact. Code-19 and paired-count claims are labelled confirmed / differs / cannot verify.
  • It does not count from the English translation. The Clear Quran (Khattab, 2022) is a translation only and was not used as a counting source.
  • It does not cover Said Nursi’s İşârâtü’l-İ‘câz — parked for now by the project owner.
